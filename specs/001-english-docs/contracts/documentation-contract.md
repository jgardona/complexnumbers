# Documentation Contract

The public API (`ComplexNumber`, `modulus`, `argument`, `topolar`, `frompolar`, `tostring`,
arithmetic operators, `conj`, `Complex(z)`) MUST keep identical signatures and behavior.

Documentation requirements after this feature:
- Every exported symbol's docstring is in English.
- Error messages are in English.
- README API reference table lists the same symbols as today, described in English.
